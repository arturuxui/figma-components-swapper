## Что нового
- **Замер внедрения AID.** В макете, до скана, — карточка «Замер внедрения AID»: выберите страницы и нажмите
  «Замерить». Плагин посчитает экземпляры по методике PD: сколько из AID, из старой библиотеки, локальных; иконки
  отдельно, скрытые отдельно; сколько старого готово к замене. Итог можно скачать или скопировать в JSON. Макет не
  меняется.
- **Карта переименований библиотек.** Плагин берёт с сервера Library Updater, что в библиотеках переименовали,
  удалили и добавили. Старое имя в макете находит наш компонент под новым (`ic_add_circle` → `ic_add_circle_fill`),
  удалённые не предлагаются, о новых окно напомнит: «пересоберите индексы». Нет связи с сервером — плагин работает
  как раньше. *Сервер карты ещё разворачивается: заработает без обновления плагина.*

## Как установить
1. Скачайте `components-swapper-v1.1.0.zip` и распакуйте.
2. В Figma Desktop: Plugins → Development → Import plugin from manifest… → `manifest.json` из распакованной папки.
   Если 1.0.0 уже импортирован — замените его папку новой (или импортируйте заново).
3. Figma спросит разрешение на сеть и на данные пользователя — это для карты переименований (сервер Library
   Updater получает только ваш id в Figma).
4. Запускайте: Plugins → Development → Components Swapper. В заголовке окна — `v1.1.0`.

Всё, что было в 1.0.0, — в [описании прошлого релиза](https://github.com/arturuxui/figma-components-swapper/releases/tag/v1.0.0).
