Первый релиз Components Swapper — плагина Figma для команды WB AID. Он находит в макетах компоненты и иконки не из
наших библиотек (Rider, Driver) и меняет их на наши, сохраняя контент. Макет меняется только по кнопке «Заменить»,
любую замену можно отменить.

## Что умеет
- **Замена по имени.** Чужой компонент → наш с тем же именем, одноимённые разводятся по размеру. Тексты сохраняются,
  вариант подбирается по осям или по устройству, старые вложенные компоненты и иконки внутри тоже меняются на наши.
  Перед заменой — примерка «Было / Будет». Неуверенные пары («Другой размер», «Выбрать») решает дизайнер.
- **Отвязанные, ручные и составные фреймы.** Отвязанный от нашего компонента — обратно в экземпляр; ручная копия
  нашего компонента и фрейм, собранный из наших компонентов, — предложение с примеркой, решает дизайнер.
- **Иконки по рисунку.** Иконка до 48 px без пары по имени сравнивается по рисунку: «Тот же рисунок» меняется сама,
  «Похож по рисунку» — выбор дизайнера; одноимённая (`Icon / Adress` = `ic_adress`) — первой в списке. Цвет иконки из
  макета переносится на нашу. Перерисованные и удалённые в библиотеке иконки плагин замечает при скане.
- **Расхождения с компонентом.** Где экземпляр в макете отличается от нашего компонента, плагин показывает разницу и
  спрашивает: ошибка макета, перенести при замене или нужен новый вариант.
- **Предложения на страницу.** Повторяющиеся в макете блоки — кандидаты в новые компоненты, и карточки «нужен вариант»
  для наших компонентов — на странице «Components Swapper · Предложения» в макете.

## Чего пока не умеет
- Отправлять предложения владельцу библиотеки — ждёт решения PD (RickOBrian/aid#185); пока карточки остаются в макете.
- Rider: в библиотеке компонентов Rider мало компонентов, поэтому много мест «Нет пары».
- Alert в Driver: в 4 местах после замены не переносятся тексты (две одинаково названные кнопки) — плагин
  предупреждает, проверьте вручную.
- Иконки одного смысла с разным рисунком (например, заливные на круге) сам не меняет — только предлагает.
- Новые иконки и компоненты библиотеки плагин видит только после пересборки индекса (см. ниже).

## Как установить
1. Скачайте `components-swapper-v1.0.0.zip` и распакуйте.
2. В Figma Desktop: Plugins → Development → Import plugin from manifest… → выберите `manifest.json` из распакованной
   папки.
3. Запускайте: Plugins → Development → Components Swapper. В заголовке окна — версия `v1.0.0`.

## Как работать
1. **Индексы библиотек — один раз и после обновлений библиотек.** Откройте файл библиотеки (Rider Components,
   Rider Icons, Driver Components, Driver Icons), запустите плагин, нажмите «Собрать индекс». Индексы хранятся в
   Figma на вашем компьютере; их список и дата — в окне плагина.
2. **Работайте на копии.** Скопируйте страницу или экраны макета на отдельную страницу и меняйте там.
3. **Скан.** Откройте макет, выделите экраны (или ничего — тогда вся страница) и нажмите «Сканировать». Плагин
   покажет группы мест: с парой, «Другой размер», «Похож по рисунку», «Нет пары» и т. д.
4. **Решения.** Проверьте предложенные пары, где нужно — выберите свою и посмотрите примерку.
5. **Замена.** «Заменить · N». После — список мест, где что-то не перенеслось, с кнопкой «Показать», и «Отменить».
